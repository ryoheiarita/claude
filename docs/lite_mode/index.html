低速遅延モード（軽量モード）

起動時にデータがそろわないとき、ロゴの下に「軽量モードで開く」を出し、8秒で自動的に切り替えます。軽量モードのHomeは、Web版と同じくArtists一覧です。アーティスト画像はアプリに同梱した単色ロゴに、その他の画像・動画は文字に置き換え、必要なものだけタップで読み込みます。

起動のシミュレーション

回線の状態を選んで再生してください。開いたあとは、アーティスト → アーティストTOP → Contentsの記事、と進めます。

起動からの経過0.0秒
3秒8秒15秒
スプラッシュボタンを表示自動で軽量モード → 15秒で再試行画面
    • 3秒・8秒・15秒はどれも仮の数値です。Remote Configで後から変えられる前提です。
    • ボタンを出したあとも裏で読み込みを続けます。途中でそろえば、通常モードで開きます。
    • 運営側からONにしている期間（フェス当日など）は、ボタンを出さずに最初から軽量モードで起動します。

    通常と軽量の比較

    Artists一覧（Web版のHome）とアーティストTOPはFigmaをもとにしています。スプラッシュは ui_prototype/splash/splash_logined、タブバーは正式コンポーネント（tabbar-260726）、記事詳細は collection/article（最新版）をそのまま使っています。各画面はスクロールできます。軽量モードの点線の枠は、タップすると画像・動画を読み込みます。

    軽量モードで止めるもの

    背景動画（同じ位置に薄いグレーのロゴを置く）、アーティスト画像、サムネイル、Libraryの表紙、Shopの商品画像、記事の写真と埋め込み動画。文字の情報とボタンの操作はすべて残します。スプラッシュ、タブバーのアイコン、記事のいいね・保存のアニメーションはアプリに入っている素材なので、軽量モードでもそのまま動かします。

    画像の代わりに出すもの

    アーティスト画像は、黒地に白の単色ロゴ（Design System V2 のロゴ）に置き換えます。12組で約21KBなのでアプリに同梱でき、通信なしで出せます。新しいアーティストのロゴは、回線が良いときに裏で取得して端末に保存します。

    入会導線は別の対応が必要

    入会ボタンから先はWebページ（bmsg.shop → Gate Page → ファンクラブLP → ログイン）です。アプリの軽量モードでは速くならないため、Gate Page を飛ばす対応や、軽い版のLPが別途必要です。
