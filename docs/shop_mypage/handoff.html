BMSG SHOP マイページ 実装指示

bmsg.shop/account（Shopify・Prestige テーマ）のマイページを、Design_System_V2 のカラーで「管理画面的なリスト表示」に作り直すための実装指示です。ヘッダー / フッター / テーマの .Button はそのまま、セクション本文（.btown-section 〜 ログアウト）のみを差し替えます。動く見本はプレビューを参照してください。

5. セクション別仕様

5-1. アカウント基本情報

  • dl.mp-dl の行（.mp-dl__row）を 5 行。PC は ラベル 160px ｜ 値 の 2 カラム grid、SP はラベル上・値下の縦積み。
  • 既存のアイコン画像（person / email / gender / cake / message / location の PNG）は廃止。ラベル文字で代替。
  • 住所はこのリストから外し、次の「登録住所」カードへ移動。
  • 値が空のときは .mp-dl__value--empty を付けて「未設定」を弱色で表示。
  • 「アカウント編集」ボタンはリスト直下（.mp-actions）。.cf-edit-account-link クラスと href は Customer Fields アプリのものをそのまま。

5-2. 登録住所（チケット先行用 / 配送用）

  • .mp-addr-grid に 2 枚の .mp-card.mp-addr。PC は 1:1 の 2 カラム、SP は縦積み。カード min-height 190px（SP は解除）。
  • カード構成: タイトル（15px/700）→ 本文（〒 / 都道府県 市区町村 / 番地 建物 / 氏名 / 電話）→ フッター（上罫線 ＋ 右寄せ「編集 ›」.mp-link）。
  • バッジ（先行受付 / 配送）は付けない。
  • 配送用 = customer.default_address。初期登録の住所をそのまま表示。「編集」は routes.account_addresses_url。
  • チケット先行用 = 保存先を確認のうえ結線（§7）。未登録時は .mp-addr--empty（破線枠・面なし）で「未登録です」＋「住所を登録 ›」。

6支払方法支払方法
  • テーブルは .mp-card.mp-card--table で包み、table.mp-table（border-collapse / table-layout: fixed / 幅 100%）。旧 .fanclub-wrap の border 重ね描画は使わない。
  • ヘッダー行は --mp-surface-2 の面 ＋ 下罫線 1px。行間は 0.5px 罫線、最終行は罫線なし。行 hover で --mp-surface-2。
  • 空セルは CSS で「—」を自動表示（td:empty::after）。Liquid 側で空文字を出せば OK。td 内に空白や改行を入れると :empty にならないので {%- -%} で空白を除去すること。
  • SP では thead を非表示にし、各 tr を --mp-surface のカードに変換。1 列目（fanclub-name）を全幅の見出し、2〜6 列目を ラベル 88px ｜ 値 の grid で並べる。ラベル文字は td::before { content: attr(data-label) }。
  • 横スクロール（旧 .sp_table_scroll）は廃止。
  • 「加入プランの管理」ボタンはテーブル直下、同幅。その下に注記 .mp-section__note。

5-4. 注文履歴

  • テーマ標準の .Segment / .PageLayout マークアップは使わず、加入済みと同じ .mp-table 様式（注文番号 / 注文日 / 支払状況 / 配送状況 / 合計）。
  • 注文 0 件は p.mp-empty（padding 40px・中央・弱色）「まだ注文していません」。

5-5. ボタン

  • 3 つ（アカウント編集 / 加入プランの管理 / ログアウト）すべて 白枠 1px・白文字・背景透過、hover で rgba(255,255,255,.08)。角丸 10px。
  • すべて display:block; width:100% で直前のリスト / カードと同幅。
  • Prestige の .Button--primary::before（白塗り）は .mp .Button::before で透過に上書き済み。ログアウトは Button--secondary でも可（見た目は同じになる）。

8. 削除するもの

  • .btown-section 内のインライン <style> 全部（.fc-text-title / .fanclub-wrap / .mypage-button / .account_wrap / .sp_table_scroll / .info-* と @media (max-width:640px)）
  • .account_wrap の ul > li > span > img（アイコン PNG 6 点）
  • .sp_table_scroll ラッパー（横スクロール）
  • #logout_btn 内の 2 つ目の「アカウント編集」（.cf-edit-account-link と .cf-edit-account-link-spacer）— 元々 display:none だったもの。残す場合は CSS で非表示のまま
  • 注文履歴の .PageLayout / .Segment マークアップ（.mp-table に置換）

9. QA チェックリスト

  1. PC 1280px: リスト・住所カード・テーブル・ボタンの左右端が揃っている（960px）
  2. SP 390px: 横スクロールが発生しない（document.documentElement.scrollWidth === 390）
  3. SP: 加入済みの各行がカードになり、ラベルが表示される（data-label 漏れがないか）
  4. 空の td に「—」が出る / 値がある td には出ない
  5. ボタン 3 つが白枠・白文字で、直前のリストと同幅
  6. ⓘ クリックでモーダルが開く・× で閉じる
  7. 「アカウント編集」が Customer Fields のフォームに飛ぶ / 「編集 ›」が住所編集に飛ぶ
  8. 注文 0 件 / 1 件以上の両方で表示確認
  9. ヘッダー・フッターに影響が出ていない（.mp 外にスタイルが漏れていない）
