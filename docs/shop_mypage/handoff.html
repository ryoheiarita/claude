bmsg.shop/account（Shopify・Prestige テーマ）のマイページを、Design_System_V2 のカラーで「管理画面的なリスト表示」に作り直すための実装指示です。ヘッダー / フッター / テーマの .Button はそのまま、セクション本文（.btown-section 〜 ログアウト）のみを差し替えます。配送用住所は複数登録・カード表示・モーダルで追加/編集します。動く見本はプレビュー（編集モーダルを開いた状態 / 追加）を参照してください。

5. セクション別仕様

5-1. 基本情報

  • dl.mp-dl の行（.mp-dl__row）を 7 行。PC は ラベル 111px（最長「メールアドレス」＋16px）｜ 値 の 2 カラム grid、SP はラベル上・値下の縦積み。
  • 既存のアイコン画像（person / email / gender / cake / message / location の PNG）は廃止。ラベル文字で代替。
  • 郵便番号・住所の行はチケット先行用（基本情報側）の住所。配送用住所とは別データ（§8）。
  • 値が空のときは .mp-dl__value--empty を付けて「未設定」を弱色で表示。
  • カード下に注記 .mp-section__note--lg「※最新の住所の反映をお願いいたします」（13px / 50%）。
  • 「基本情報の編集」は PC: 見出し右（内容幅）、SP: 注記の下に全幅。.cf-edit-account-link クラスと href は Customer Fields アプリのものをそのまま。

5-2. 配送用住所（複数）

  • customer.addresses をループして article.mp-card.mp-addr を並べる。.mp-addr-cards は PC 3 列 grid（gap 16）、SP 1 列（gap 12）。同じ行のカードは高さが揃う（align-items: stretch）。
  • カード構成: Head（氏名 15px Bold ＋ デフォルト住所のみ .mp-pill「選択中」白地/黒文字）→ Body（〒 / 都道府県 市区町村 / 番地 建物 / 会社名 / 電話、14px 75% lh 24）→ Foot（上罫線 0.5 ＋ 右寄せ「削除」「編集 ›」）。
  • 編集: そのカードのモーダル #addr-modal-{address.id} を開く。削除: POST /account/addresses/{id}（_method=delete）を confirm 付きで送信。
  • 追加カード .mp-addr--add: 破線枠（白25% 1px）・透過・中央に「＋ 配送用住所を追加」。customer.addresses_count < 10 のときだけ表示（Shopify の上限）。クリックで #addr-modal-new。
  • 見出し下に補足「複数の配送先を登録できます。注文時に選択する住所です。」。旧「配送用住所の編集」ボタンは廃止。

10. QA チェックリスト

  1. PC 1280px: リスト・住所カード・テーブル・ボタンの左右端が揃っている（1000px）。見出し右のボタンが見出しと垂直中央で揃う
  2. SP 390px: 横スクロールが発生しない（document.documentElement.scrollWidth === 390）。見出し右ボタンが消え、リスト下に全幅ボタンが出る
  3. 基本情報 7 行・ラベル列 111px。注記「※最新の住所…」がカード直下に出る
  4. 配送用住所: デフォルト住所にだけ「選択中」。住所 0 件でも追加カードが出る / 10 件で追加カードが消える
  5. 編集 › で該当住所が入ったモーダル、＋ で空のモーダルが開く。× / 背景 / Esc で閉じる
  6. 国を変えると都道府県セレクトが切り替わる。必須未入力で送信できない。保存後に一覧へ反映される
  7. 削除で confirm → 一覧から消える。デフォルト住所を消した場合の挙動（Shopify 側で繰り上げ）を確認
  8. SP: 加入済みの各行がカードになり、ラベルが表示される（data-label 漏れがないか）。空の td に「—」
  9. ⓘ クリックで情報モーダルが開く・× で閉じる（住所モーダルと競合しない）
  10. 注文 0 件 / 1 件以上の両方で表示確認
  11. ヘッダー・フッターに影響が出ていない（.mp / .mp-modal 外にスタイルが漏れていない）

  // モーダル開閉 + 都道府県セレクト + 削除確認
  (function () {
    function open(id) { var m = document.getElementById(id); if (!m) return; m.hidden = false; document.body.style.overflow = 'hidden'; var f = m.querySelector('input:not([type=hidden])'); if (f) setTimeout(function () { f.focus(); }, 0); }
    function closeAll() { document.querySelectorAll('.mp-modal').forEach(function (m) { m.hidden = true; }); document.body.style.overflow = ''; }
    document.addEventListener('click', function (e) {
      var o = e.target.closest('[data-modal-open]'); if (o) { open(o.getAttribute('data-modal-open')); return; }
      if (e.target.closest('[data-modal-close]') || e.target.classList.contains('mp-modal')) closeAll();
    });
    document.addEventListener('keydown', function (e) { if (e.key === 'Escape') closeAll(); });
    document.querySelectorAll('form[data-confirm]').forEach(function (f) { f.addEventListener('submit', function (e) { if (!confirm(f.getAttribute('data-confirm'))) e.preventDefault(); }); });
    // 国 → 都道府県（Shopify 標準）
    function initProvinces() {
      if (!window.Shopify || !Shopify.CountryProvinceSelector) return;
      document.querySelectorAll('.mp-modal select[id^="addr-country-"]').forEach(function (c) {
        var id = c.id.replace('addr-country-', '');
        new Shopify.CountryProvinceSelector('addr-country-' + id, 'addr-province-' + id, { hideElement: 'addr-province-' + id });
        var p = document.getElementById('addr-province-' + id); var def = p && p.getAttribute('data-default'); if (def) p.value = def;
      });
    }
    if (document.readyState === 'loading') document.addEventListener('DOMContentLoaded', initProvinces); else initProvinces();
  })();
</script>
