グループトーク 収録モード

アーティスト同士は決まった時間内に自由に話し、そのあいだファンにはまだ出しません。収録が終わったら審査マネが中身を見て、消す投稿だけを選び（必要なら書き換えて）、話した順番のままファンに公開します。

①審査は外せない → 公開前に必ずマネが見る ②LINEのようなテンポ → アーティスト同士はリアルタイム ③投稿順を守る → 話した順で公開

19:59:40 収録前
状態へスキップ 今のシナリオ（A／B）をその状態まで進めて一時停止します。「再開」で続きから動きます

このプロトの決まりごと

  • 開始はマネがナビ右上の「収録」ボタンから。アクションシートで「今すぐ収録を開始」か「日時を指定して予約」（終了は任意）を選ぶ。予約は時刻になると自動で開始
  • 収録前（予約なし）は上部バーを出さない
  • 予約中は、全員の画面の上部バーに「2026年11月18日 20:00 から収録を開始します」、ナビ右上に開始時刻を表示。予約するとアーティストに通知（ログに表示）。予約後はナビ右上が「予約済み 20:00」になり、そこから前倒し開始・変更・取消ができる
  • 準備完了の確認はしない。マネの画面で誰がルームにいるかだけ見える。遅れて来ても話した順に公開される
  • 収録中だけ投稿できる。アーティスト同士の投稿はお互いにすぐ見え、ファンには出ない（ファン画面では収録していることも知らせない）。トークルーム上部に「収録中」、ナビ右上に「REC」
  • 終わり方は、予約や開始時に決めた終了時刻か、マネの「収録を終了」。上限は30分
  • 収録中はナビ右上が「収録終了」、確認中は「公開」になる。終了後はマネが確認（削除・書き換え）→「公開」から「今すぐ公開」か「送信予約」。送信予約中も公開までは削除・書き換えができ、予約の変更・取消もできる
  • 投稿の時刻表示は、収録中・確認中は収録開始からの経過時間（0:21 など）。公開後はアーティスト・マネ・ファンとも公開時刻を起点にした時刻（20:05 公開なら 20:05〜）
  • 返信がついた投稿を削除すると、返信は引用なしで公開される。「返信も削除」も選べる

決めたいこと

  • 収録していないとき、アーティストは投稿できない前提でよいか
  • 収録予約を設定できるのはマネだけか（アーティストからの申請も受けるか）
  • 予約の項目は「開始日時だけ」か「開始＋終了（任意）」か
  • 準備完了制は入れず、在室の表示だけでよいか
  • 送信予約のときの流し方（話した間隔で流す／まとめて出す）は、今すぐ公開と同じでよいか
  • 公開前に次の収録を始めてよいか
  • 審査なしのアーティストの投稿も、マネが削除・書き換えしてよいか／書き換えを本人に通知するか
