グループトーク 収録モード

アーティスト同士は決まった時間内に自由に話し、そのあいだファンにはまだ出しません。収録が終わったら審査マネが中身を見て、消す投稿だけを選び（必要なら書き換えて）、話した順番のままファンに公開します。

①審査は外せない → 公開前に必ずマネが見る ②LINEのようなテンポ → アーティスト同士はリアルタイム ③投稿順を守る → 話した順で公開

このプロトの決まりごと

  • 収録中、アーティスト同士の投稿はお互いにすぐ見える。ファンには出ない
  • 終わり方は、予約なら「予約した終了時刻」、マネ開始なら「開始ダイアログで決めた終了時刻（指定しなくてもよい）」。どちらもマネが手動で終了でき、上限は30分
  • 収録中はトークルームの上部に「収録中」を表示。予約の場合は、始まるまで画面右上に収録開始時刻を表示
  • マネは収録中から削除を選び始められる。終了後は「削除」と「書き換え」だけ行い、問題なければ何もしない（＝全部公開）
  • 返信がついた投稿を削除すると、返信は引用なしで公開される。「返信も削除」も選べる
  • 公開後、アーティストのアプリには削除・書き換えの結果が表示される

決めたいこと

  • 予約とマネ開始のどちらを基本にするか（両方持つか）と、終わり方の組み合わせ
  • ファンへの公開を「話した間隔で流す」か「まとめて出す」か
  • 表示時刻を「話した時刻」にするか「公開した時刻」にするか（現行の「送信日時＝承認時刻」の変更になる）
  • 審査なしのアーティストの投稿も、マネが削除・書き換えしてよいか
  • 書き換えを本人に通知するか、了承を取るか
  • 収録中、ファンに「収録中」と知らせるか
