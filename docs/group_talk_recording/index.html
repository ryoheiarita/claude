グループトーク 収録モード

19:59:40 収録前

概要

審査はアーティストグループごとにマネ1人が担当し、ソロアーティストは審査なしです。収録モードは、審査ありと審査なしのアーティストが混ざるグループトークを、まとめて審査できるようにする機能です。

アーティストの投稿は、ふだんはマネが1件ずつ審査（承認／削除）し、承認した時点でファンに公開されます。

収録モードは、この審査をまとめて行う機能です。収録中はアーティスト同士がリアルタイムで自由に話し、ファンにはまだ出しません。終わったらマネが中身を確認し、消すものだけ選んで（必要なら書き換えて）、話した順番のまま公開します。

通常の投稿と収録はシームレスに行き来できます。ただし収録中は、収録が終わるまで通常の投稿はできません（投稿はすべて収録分になる）。

各ステップを押すと、その状態の画面まで進めて止まります。「再開」で続きから動きます。

  1. 1収録前
    • マネが右上の「収録」→「今すぐ収録を開始」か「日時を指定して予約」
    • 未審査の通常の投稿が残っているときは「収録を始める前に審査を完了してください」のアラートを出す
    • 予約は開始日時だけを設定。全員の画面上部に「2026年11月18日 20:00 から収録を開始します」、右上に開始時刻。時刻になると自動で開始
    • 予約後も「予約済み」から前倒し開始・変更・取消ができる
    • 収録前は通常の投稿。マネの画面に「承認／削除」が出て、承認するとその時刻でファンに公開される（未審査の間はグレー）
    • アーティストの準備完了は待たない
  2. 2収録中
    • 投稿はすべて収録分になり、通常の投稿はできない。アーティスト同士はリアルタイムでやり取りでき、返信もできる
    • 画面上部に「収録中」、右上に「REC」（マネは「収録終了」ボタン）
    • 投稿の時刻は「開始後 0:21」のように収録開始からの経過時間
    • 決めた終了時刻か、マネの「収録終了」で終わる（上限30分）
    • ファンには何も出さない（収録していることも知らせない）
  3. 3確認中
    • マネは各投稿の「•••」から「削除」か「書き換え」だけ。問題なければ何もしない
    • 返信が付いた投稿を削除すると、返信は引用なしで公開。「返信も削除」も選べる
    • アーティストにもマネの削除・書き換えが見える
  4. 4確認後・公開前
    • 右上の「公開」→「今すぐ公開」か「送信予約」
    • 送信予約中は時刻が「20:05 予定」、削除した投稿は「削除」
    • 公開までは削除・書き換え、予約の変更・取消ができる
  5. 5公開後
    • ファンには話した間隔のまま順番に流れる。時刻は公開時刻が起点（20:05 公開なら 20:05〜）
    • 削除した投稿は全員の画面から消える
    • 公開後は通常の投稿に戻る（1件ずつ審査）
    • 収録分は角丸の背景でまとめ、上に「収録 20:00:00〜20:03:00」、下に「公開済み 2026/11/18 20:05」。公開後は上部バーを出さない

このプロトの決まりごと

  • 開始・予約・終了・公開の操作はマネだけ。ナビ右上のボタンが状態に合わせて「収録 → 予約済み → 収録終了 → 公開」と変わり、押すとアクションシートが出る
  • 予約の項目は開始日時だけ。予約するとアーティストに通知が届く想定
  • 公開はファンに話した間隔のまま流す
  • 審査なしのアーティストの投稿も、マネがすべて見られる（削除・書き換えできる）
  • 収録前（予約なし）は上部バーを出さない
  • トークルームには、通常の投稿と収録のまとまりが時刻順に並ぶ
  • 遅れて来たアーティストの投稿も、収録内では話した順に公開される

決めたいこと

  • 収録が終わってから公開までの間に通常の投稿を承認すると、収録分より先にファンに出る。許容するか、公開まで止めるか
  • 収録を始めるときに未審査の通常の投稿が残っていたら、「収録を始める前に審査を完了してください」のアラートを出す、でよいか
  • 公開前に次の収録を始めてよいか
  • マネが書き換えたことを本人に通知するか
  • 複数のアーティストがいるとマネも複数いるが、このグループトークに設定した審査者を、収録モードを審査する人として扱ってよいか
