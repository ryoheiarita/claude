bwu_admin 俯瞰図

bwu app のインナー管理画面。要件定義・確定した仕様・動くプロトタイプを、ひとつの場所で管理する。

draft · 構想段階
目的

要件定義の置き場所を明確にし、要件定義された仕様を誰もが確認でき、プロトタイプを動くもので共有できる状態を、ひとつの場所で一括管理する。

  • 置き場所の明確化要件定義はチケット単位で admin に格納。探さなくても見つかる
  • 仕様を誰でも確認確定した仕様は Wiki の機能ディレクトリで全員が同じものを見る
  • 動くもので共有プロトタイプは画像ではなく URL で開ける実物として共有
  • 一括管理要件・仕様・プロト・入稿物をチケットで束ね、Notion / Figma / Git と同期
前提
利用者
bwu のデザイン / PdM / 開発メンバー（インナー限定）
正本
チケットは Notion、デザインは Figma、コードは Git。admin はその間を繋ぐ作業場
成果物
チケットに紐づいた要件定義・確定仕様・動くプロトタイプ・入稿物
UI
bwu トンマナ（#101010 / #2aa7ff / Figtree）の shadcn 的管理画面

03

動くプロトで共有
