グループトーク 収録デフォルト

20:00:00 収録中

概要

収録モードを常にオンにしたパターンです。グループトークの投稿は、いつでもすべて「収録」として扱います。収録の開始や終了の操作はなく、開始時刻も決めません。

アーティストはいつでも自由に話せます。投稿はすぐにはファンに出ず、「未審査」のまとまりにたまっていきます。

マネは好きなタイミングで「ここまで」を区切って審査します。消すものだけ選び、必要なら書き換えて、いつ送信するか（今すぐ／送信予約）を決めます。公開すると、話した順番と間隔のままファンに流れます。

区切ったあとの投稿は、次の未審査のまとまりに入ります。審査中もアーティストは話し続けられます。

各ステップを押すと、その状態の画面まで進めて止まります。「再開」で続きから動きます。

  1. 1話す（いつも収録中）
    • アーティストはいつでも投稿・返信できる。開始・終了の操作も予約もない
    • 投稿は灰色のまとまり「収録中・未審査」にたまり、ファンには出ない
    • 投稿の時刻は「20:00:21」のように秒まで出す
    • マネの画面上部に「未審査 n件」
  2. 2ここまでを審査
    • マネが右上の「審査」→「ここまでを審査（n件）」。投稿の「•••」→「この投稿までを審査」で途中で区切ることもできる
    • 区切った分は「確認中」のまとまりになる。区切ったあとの投稿は次の未審査に入る（審査中も話し続けられる）
    • マネは各投稿の「•••」から「削除」か「書き換え」だけ。返信が付いた投稿を消すときは「返信も削除」も選べる
    • アーティストにもマネの削除・書き換えが見える
  3. 3いつ送信するか決める
    • 右上の「公開」→「今すぐ公開」か「送信予約」
    • 送信予約中は時刻が「20:03 予定」、削除した投稿は「削除」
    • 公開までは削除・書き換え、予約の変更・取消ができる
  4. 4公開
    • ファンには話した間隔のまま順番に流れる。時刻は公開時刻が起点
    • 削除した投稿は全員の画面から消える
    • まとまりの下に「公開済み 2026/11/18 20:03」
  5. 5次の区切り
    • 審査中に届いた投稿は、そのまま次の未審査のまとまりになっている
    • 同じように区切って審査・送信する。前の分が流れている途中なら、流し終わってから続けて流す

このプロトの決まりごと

  • 収録の開始・終了・予約はない。投稿はすべて未審査として入り、マネが区切って審査する
  • 区切る・公開する操作はマネだけ。ナビ右上のボタンが「審査 → 公開 → 公開予定」と変わり、押すとアクションシートが出る
  • 確認中・公開予約中のまとまりがある間は、次の区切りは作れない（1つずつ審査）
  • 公開はファンに話した間隔のまま流す
  • 審査なしのアーティストの投稿も、マネがすべて見られる（削除・書き換えできる）

決めたいこと

  • 確認中の間に、さらに次の区切りを作れるようにするか（今は1つずつ）
  • 前の公開分がファンに流れている途中で次を公開したら、流し終わってから続けて流す、でよいか
  • マネが区切らずに放置したときの扱い（一定時間・件数でマネに通知する、など）
  • ソロ（審査なし）のトークは今までどおり即時公開のままでよいか
  • マネが書き換えたことを本人に通知するか
