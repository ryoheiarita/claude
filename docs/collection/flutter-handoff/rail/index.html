3アイコンの大きさ（調整済み・ここが要点）

ボタンは 48 で共通ですが、中のアイコンは素材ごとに実寸がバラつくため、 見かけの大きさが 18px 相当で揃うように調整済みです。以下が現物の実測値（停止状態）。

🔖 bookmark11.9 × 16.872×721.0（素材のまま）縦長の素材。高さで揃う

  • ♥🔖：Lottie を 72×72 のキャンバスに置いて素材原寸のまま表示（バースト粒子がボタン外へ出るため大きめの箱が必要）。
  • 💬📄：Lottie を 24×24 のホルダーに置き、読み込み後に中身の長辺 = 18px・中心をボタン中央に合わせて拡縮（参照実装の _fitOnce()）。
  • Flutter では動的計算は不要。上表の「適用スケール」を素材ごとに固定値として焼き込んでください（結果は 💬📄⛶ とも見かけ 18×18）。

6💬 コメントボタンのアイコン巡回（アーティストコメントがある時）

そのコンテンツにアーティスト本人のコメントが付いている場合だけ、コメントボタンの中身が 吹き出しアイコン ⇄ アーティストのアバターに「ポワン」と切り替わりながら巡回します。 「アーティストが喋っている」ことをレール上で気づかせるための表現で、ボタンの背景ピル（円・blur・ボーダー）はそのまま、中身だけが差し替わります。

アーティスト3人の場合（実物・等倍）
吹き出し → ① → ② → ③ → 吹き出し…
アーティストコメントが無い場合
巡回しない（吹き出し固定）
発火条件アーティスト本人のコメントが有るsetCommentArtists(urls)
人数最大3人（4人目以降は出さない）≤ 3
アバター保持1面あたり1.0s
吹き出し保持1周して戻った時の休止5.0s
初回開始画面表示から1.0s
アバター円・cover・白リング30 / 1.5px 85%
項目仕様
巡回順吹き出し → アーティスト① → ② → ③ → 吹き出し …（無限ループ）
保持時間アーティストは各 1.0s。1周して吹き出しに戻ったら5.0s 待機してから次の周へ（＝吹き出しが基準・休止点）。等間隔ではない可変ディレイ（index 0 に戻ったら 5s、それ以外は 1s）
初回画面表示から 1.0s 後に最初の切替が始まる
切替アニメ（入り）scale 0→1 / 0.40s cubic-bezier(0.34, 1.56, 0.64, 1)（オーバーシュートで弾む）＋ opacity 0→1 / 0.26s
切替アニメ（抜け）scale 1→0 / 0.28s cubic-bezier(0.4, 0, 1, 1)（素早く縮む）＋ opacity 1→0 / 0.18s
入り・抜けの関係同時進行（前の面が縮みながら次の面が弾んで出る）＝「ポワン」
アバターの見た目30×30 円 / object-fit: cover / 白 1.5px リング box-shadow 0 0 0 1.5px rgba(255,255,255,0.85)（アーティストと分かる縁取り）
アーティストコメントが無い時巡回しない。通常の吹き出しアイコンで固定（API 的には setCommentArtists([])）
シート開閉との関係独立。巡回中でもタップでコメントシートが開き、アクティブ白枠も通常どおり付く
  • Flutter 実装方針：コメントボタンを Stack + AnimatedScale/AnimatedOpacity（または AnimatedSwitcher）で。子 = [吹き出し, avatar①, avatar②, avatar③] を index で切替。タイマは「index が 0 に戻ったら 5s、それ以外は 1s」の可変ディレイ。カーブは入り Curves.easeOutBack 相当、抜け Curves.easeIn 相当。
  • 参照実装: bwu-action-rail.js の setCommentArtists(urls)（アバターURL配列・最大3を渡すと開始、空配列で通常アイコンへ）。属性でも指定可 comment-artists="url1,url2,url3"。
  • プロトタイプでの配線例は 縦動画 ph3（アバターは仮のグラデ画像。本番はアーティストのアバターURLを渡す）。
