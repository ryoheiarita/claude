タブバー 260726(アニメアイコン + More展開メニュー)

フローティングタブバーの Flutter 実装指示。バーの形状は既存タブバー(checkin_motion と同一)、 バー4タブ + Moreメニュー3項目のアイコンは animated iconsax の Lottie。 More タップで白丸反転 + 3つのサテライトが展開し、背景のグラデーションが blur 付きに切り替わる。 デザイン: Figma Design_System_V2 Tabbar_set 322:1202 (Default 261:414 / Opened 316:1059)。 動作デモはこちら(スマホで開くと実寸)。

More を押すと、背景が沈む

中央の More をタップすると丸が白へ反転し、バーの上に3つのメニューが展開する。 同時に背景のグラデーションが切り替わり、上に向かって消えていくぼかしがかかる。 この文字のぼけ方で、blur が効いているかを確認できる。
実物のタブバー(このページに埋め込み・操作できます)。
More をタップ → 展開 / サテライトをタップ → 閉じて中央 More に反映 / タブをタップ → アイコン再生

1. アセット(このファイル一式をそのまま使う)

アイコンは支給の Lottie JSON をそのまま使用(加工不要)。白ストローク焼き込みなので色指定は不要、非アクティブは opacity で表現する。

More の選択状態(中央ボタンへの反映)

サテライト(Check In / Gallery / Calendar)を選ぶとメニューは閉じ、 中央の More ボタンが白背景 + 選んだアイコン(黒) + 選んだラベルに変わる (= 現在地がその項目であることを示す)。

状態中央ボタンの見え方
通常すりガラス丸(白25%)+ HANAロゴ 白75% / ラベル「More」白50%
メニュー展開中白丸 + HANAロゴ 黒 / ラベル「More」
選択中白丸 + 選んだ項目のアイコン(黒) / ラベルはその項目名・白100%(例「Calendar」)
解除バーのタブ(Home 等)をタップすると解除され、通常の More に戻る

アイコンは同じ Lottie を流用し、白背景に載るため黒へ反転させる (CSS: filter:invert(1) / Flutter: ColorFiltered(ColorFilter.mode(Colors.black, BlendMode.srcIn)))。 選択時にそのアイコンを1回再生する。微調整値(scale/dx/dy)はサテライトと同じ値を中央でも適用する。

背景グラデーション(バーの背面・高さ 268 / 完全再現ポイント)

状態値
通常時 261:414linear-gradient(180deg, rgba(0,0,0,0) 52.404%, rgba(0,0,0,0.6) 100%) / blur なし
展開時 316:1059linear-gradient(180deg, rgba(16,16,16,0) 0%, #101010 100%) + background blur 32(下記)
切替色グラデは opacity クロスフェード 0.3s ease / blur は半径 0 → 32 をアニメーション
重なり順コンテンツ < ①通常グラデ → ②blur層 → ③展開グラデ < スクリム < バー/メニュー
展開時の blur は「上に向かって透明になる blur」。 Figma の background-blur はレイヤー自身のアルファで変調されるため、グラデが透明な 上側では blur も効かず、下へ行くほど強くかかる(上端 blur 0 → 下端 blur 32 の連続変化)。 一様な全面 blur にしないこと。

実装:
・Flutter → blur 層を ShaderMask(BlendMode.dstIn + 縦グラデ transparent→black)で抜く。TabBarBg260726 に実装済み。
・CSS → blur 層に mask-image: linear-gradient(180deg, transparent 0%, #000 100%)。
・フェードは opacity ではなく blur 半径(sigma)をアニメーションさせる (opacity を動かすと合成レイヤー化して blur が一時的に消える)。

3. アニメーション仕様

Lottie 再生(タップで1回)

タブ/サテライトのタップで該当アイコンの Lottie を1回再生。各 Lottie の冒頭には 160〜534ms の「何も動かないフレーム」が焼き込まれているため、下表の開始位置から再生する (dart では kIconStartFraction として定義済み — controller.forward(from: fraction))。

4. Flutter 組み込み

tab_bar_260726.dart は完成済み。Stack 内に背景グラデ → バーの順で重ねる:

bool _moreOpen = false;
int _tab = 0;

Stack(children: [
  /* ...screen content... */

  // 背景グラデ(通常/展開でクロスフェード、blurは展開時のみ)
  Positioned(left: 0, right: 0, bottom: 0,
    child: TabBarBg260726(open: _moreOpen)),

  // タブバー本体(Moreメニュー込み)
  Positioned(left: 0, right: 0, bottom: 24,
    child: Center(child: TabBar260726(
      index: _tab,
      onChanged: (i) => setState(() => _tab = i),
      onMoreItem: (key) { /* 'checkin' | 'gallery' | 'calendar' で画面遷移 */ },
      onMoreOpenChanged: (open) => setState(() => _moreOpen = open),
    ))),
])

微調整値(kMoreSpec / kTabAdjust)はデザイナー側のツールから出力された ブロックをそのまま貼り替える運用。デモページの表示は tabbar-adjust.js(確定値)と一致しており、 Dart 側の定数もこれと同じ値に揃えてあるので、デモと実装が食い違うことはない。

5. 実装上の注意(ハマりどころ)

① blur の入れ子: バーの blur の内側に More 丸・サテライトの blur がある。 Flutter は BackdropFilter の入れ子で問題ないが、Web/CSS 実装の場合は 祖先に backdrop-filter を置くと内側が無効化されるため、バーの blur は擬似要素(::before)に置くこと。
② 中央ボタンのはみ出し: バー h64 に対し中央ボタンは h75(丸がバー上端から10pxはみ出す)。 クリッピングしないこと(Clip.none / overflow visible)。CSS実装では box-sizing:border-box 必須 (無いとバーが78pxに膨らみ、はみ出しが消える — 実際に起きたバグ)。
③ バーを動かすアニメ: 出入りやスクロール連動でバーを動かす場合、 CSS では transform/opacity ではなく bottom 等のレイアウトプロパティで(transformを充てると blur が 一時停止する)。Flutter では通常問題なし。
④ Lottie の死に時間: 冒頭スキップ(§3の表)を入れないと 「タップしたのに反応が遅い」と感じる。kIconStartFraction を必ず使うこと。
